FLEET FUEL MANAGER
==================
1. Install Node.js (LTS) from https://nodejs.org  (one time).
2. Windows: double-click start.bat.   Mac/Linux: run  node server.js
3. Open http://localhost:3000 in your browser.
   Other computers/phones on the same network: use the "On your network" address shown in the window.

Password: set FLEET_PASSWORD before starting (see start.bat). The browser will ask for a login;
username can be anything, password is what you set.

Your data is in the "data" folder (records.json). A daily backup copy is made automatically.
Copy that folder to back up or move the system to another computer.
To use it from outside your office you must host it on a server (and use HTTPS + a password).
